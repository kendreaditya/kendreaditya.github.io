# Accent fonts

These alphabet-only WOFF2 subsets are self-hosted copies served by the current
minimal site:

- Caveat Regular (`v23`)
- Righteous Regular (`v18`)
- Zilla Slab Regular (`v12`)

They were obtained from the Google Fonts CSS API with the subset text
`ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz ` and are licensed under the
SIL Open Font License 1.1. The corresponding license text for each family is in
this directory.
